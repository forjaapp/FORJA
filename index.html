Instalar FORJA

Instalala para usarla como una app.

Funciona en iPhone, Android y computadoras con Windows o Mac. Los datos se guardan en cada dispositivo: para pasarlos a otro, usá la copia JSON.

Tu plan anual

Configurá cada día en la sección «Tu Rutina»: grupos musculares, ejercicios elegidos, series y descanso general. Entrenar muestra únicamente tu configuración y el registro diario. Los entrenamientos guardados conservan su propia copia aunque edites el plan.

Privacidad y reinicio

Los registros de entrenamiento no se envían a internet; las fotos de la guía pueden descargarse del sitio público de Free Exercise DB. Si cambiás el dominio de publicación, navegador o dispositivo, importá una copia JSON para recuperar tus registros.

Algunos visores de archivos de iPhone no ejecutan JavaScript o no conservan los datos. Para uso persistente, abrí el HTML como página en un navegador compatible. Si el indicador superior avisa que el guardado no está disponible, exportá copias con frecuencia.
